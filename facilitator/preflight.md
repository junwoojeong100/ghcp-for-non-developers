# Facilitator pre-flight checklist

> Print this. Run it top to bottom before every workshop. 90% of on-site failures are killed at T-7 days.

## T-7 days — accounts & access

- [ ] Every participant has a **GitHub account** (username collected)
- [ ] Every participant has **Copilot access confirmed** — they can open [github.com/copilot](https://github.com/copilot) and get a reply (Free plan is fine; company accounts need the **GitHub Copilot app** policy enabled — it is by default)
- [ ] Send the install homework: **Git** ([install guide](https://github.com/git-guides/install-git)) + **GitHub Copilot app** ([download](https://github.com/features/ai/github-app)) + "sign in once before the workshop"
- [ ] Repo access sorted: repo public, or all participants invited (private)

## T-1 day — environment

- [ ] You ran **Labs 0–5 yourself this week** on the same OS participants will use (UIs drift)
- [ ] Screenshots of your own outputs saved as **demo insurance**
- [ ] Venue wifi reaches `github.com` and Copilot endpoints (test from a personal hotspot too, as plan B)
- [ ] Projector laptop: app installed, signed in, project already connected
- [ ] Print or link this repo's **verification checklist** for every seat

## Day of — room setup (30 min before)

- [ ] Pairs assigned: **driver** types, **navigator** reads checkpoints aloud, swap each lab
- [ ] Norm on the wall/slide: *"Your output will differ from your neighbor's and from mine. We check properties, not word-for-word matches."*
- [ ] Timebox visible:

| Block | Time |
| --- | --- |
| Welcome + Part 1 concepts | 25 min |
| Lab 0 setup | 20 min (buffer +10) |
| Labs 1–2 | 35 min |
| Break | 10 min |
| Labs 3–4 | 45 min |
| Lab 5 | 25 min |
| Labs 6–7 + demos | 50 min |

## When things go wrong — plan B ladder

1. **One person's app won't sign in** → pair them as navigator; fix during break
2. **Git missing** → install (~3 min) → restart app; meanwhile they shadow their pair
3. **Wifi blocks Copilot** → hotspot; if venue-wide, fall back to demo-driven walkthrough with your screenshots
4. **Agent gives a weird answer on the projector** → best teaching moment: debug the four-part request live
5. **Someone races ahead** → point them at the 💡 *Going further* lines and Bonus Labs
