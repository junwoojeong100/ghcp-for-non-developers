# 진행자 사전점검 체크리스트

> 인쇄해서 위에서 아래로 확인하세요. 현장 장애의 90%는 D-7에서 잡힙니다.

## D-7 — 계정과 권한

- [ ] 모든 참가자가 **GitHub 계정** 보유 (아이디 수합 완료)
- [ ] 모든 참가자의 **Copilot 사용 가능 확인** — [github.com/copilot](https://github.com/copilot)에서 답변을 받아봤는지 (Free 플랜 OK; 회사 계정은 **GitHub Copilot app** 정책 활성화 필요 — 기본값은 켜짐)
- [ ] 설치 숙제 발송: **Git**([설치 안내](https://github.com/git-guides/install-git)) + **GitHub Copilot 앱**([다운로드](https://github.com/features/ai/github-app)) + "워크숍 전에 한 번 로그인해 보기"
- [ ] 리포 접근 정리: 공개 전환 또는 (비공개 시) 전원 초대 완료

## D-1 — 환경

- [ ] 진행자 본인이 **이번 주에 Lab 0~5를 직접** 참가자와 같은 OS에서 완주 (UI는 계속 바뀝니다)
- [ ] 내 결과물 스크린샷을 **시연 보험**으로 저장
- [ ] 행사장 와이파이에서 `github.com`과 Copilot 엔드포인트 접속 확인 (플랜 B로 핫스팟도 테스트)
- [ ] 프로젝터 노트북: 앱 설치·로그인·프로젝트 연결까지 완료
- [ ] 좌석마다 이 리포의 **검증 체크리스트** 인쇄물 또는 링크 준비

## 당일 — 장소 세팅 (시작 30분 전)

- [ ] 짝 배정: **드라이버**가 입력, **내비게이터**가 체크포인트 낭독, 랩마다 교대
- [ ] 화면/벽에 규칙 게시: *"여러분의 결과는 옆 사람과도, 저와도 다릅니다. 우리는 단어가 아니라 속성을 확인합니다."*
- [ ] 타임박스 게시:

| 블록 | 시간 |
| --- | --- |
| 환영 + 개념편 | 25분 |
| Lab 0 세팅 | 20분 (버퍼 +10) |
| Lab 1~2 | 35분 |
| 휴식 | 10분 |
| Lab 3~4 | 45분 |
| Lab 5 | 25분 |
| Lab 6~7 + 발표 | 50분 |

## 문제 발생 시 — 플랜 B 사다리

1. **한 명이 로그인 불가** → 내비게이터로 짝 배치, 휴식 시간에 해결
2. **Git 미설치** → 설치(~3분) → 앱 재시작, 그동안 짝 화면 관찰
3. **와이파이가 Copilot 차단** → 핫스팟; 전면 차단이면 스크린샷 기반 시연으로 전환
4. **프로젝터에서 이상한 답변** → 최고의 교육 순간: 4요소 요청을 현장에서 함께 디버깅
5. **진도가 빠른 참가자** → 💡 *더 해보기*와 보너스 랩으로 안내
