# 클라우드베리 주문 대시보드 사양

## 목적과 데이터 기준

- **원본:** `my-work/orders-clean.csv`
- **분석 단위:** 완전 중복을 제거한 주문번호별 행
- **유효 매출 행:** 수량과 단가가 모두 있고 수량이 0보다 큰 행
- **매출 제외:** 주문 1005(단가 누락), 1008(수량 -1), 1018(수량 누락)
- **유효 주문 행:** 수량이 있고 0보다 큰 행. 단가 누락은 주문 수에는 포함하되 매출에는 제외한다.
- 주문 1006의 날짜 `2026-08-04`는 다른 행을 근거로 연도를 보정한 값이므로 확인 전까지 **가정**으로 표시한다.

## 질문 1 — 어떤 상품이 매출을 가장 많이 만드는가?

| 항목 | 사양 |
|---|---|
| 지표 | 상품별 유효 매출 |
| 정확한 계산식 | `상품별 유효 매출 = Σ(수량 × 단가) WHERE 수량 IS NOT NULL AND 수량 > 0 AND 단가 IS NOT NULL`, 상품으로 그룹화 |
| 차트 | 가로 막대 차트, 매출 내림차순 |
| 필요한 필드 | 주문번호, 상품, 수량, 단가 |
| 표시 규칙 | 금액은 원 단위, 막대 끝에 값 표시, 제외 행 수를 차트 아래 주석으로 표시 |
| 검산 기준 | 1위 `젤펜 0.5mm` 90,000원, 전체 유효 매출 295,750원 |

## 질문 2 — 어느 채널에서 분석 가능한 주문이 가장 많이 발생했는가?

| 항목 | 사양 |
|---|---|
| 지표 | 채널별 유효 고유 주문 수 |
| 정확한 계산식 | `채널별 유효 주문 수 = COUNT(DISTINCT 주문번호) WHERE 수량 IS NOT NULL AND 수량 > 0`, 채널로 그룹화 |
| 차트 | 세로 막대 차트 |
| 필요한 필드 | 주문번호, 채널, 수량 |
| 표시 규칙 | Y축은 주문 건수, 각 막대 위에 건수 표시, 수량 미확정·음수 행 제외 사실을 주석으로 표시 |
| 검산 기준 | 웹 13건, 매장 3건, 팝업 2건 |

## 질문 3 — 일별 유효 매출 흐름과 최고 매출일은 언제인가?

| 항목 | 사양 |
|---|---|
| 지표 | 일별 유효 매출 |
| 정확한 계산식 | `일별 유효 매출 = Σ(수량 × 단가) WHERE 수량 IS NOT NULL AND 수량 > 0 AND 단가 IS NOT NULL`, 주문일로 그룹화 |
| 차트 | 날짜 순 선 차트 |
| 필요한 필드 | 주문번호, 주문일, 수량, 단가 |
| 표시 규칙 | 2026-08-01부터 2026-08-15까지 날짜축을 연속 표시하고, 유효 매출 행이 없는 날은 0원으로 표시하되 판단 보류 행이 있으면 별도 표식 추가 |
| 검산 기준 | 최고 매출일 `2026-08-10`, 37,000원 |

## 공통 필터와 품질 표시

- 채널, 상품, 도시, 주문일 범위 필터
- 마지막 정제일과 사용한 파일명
- 매출 제외 행 3건과 주문번호 `1005, 1008, 1018`
- 사람 판단 필요 행 2건과 주문번호 `1008, 1018`
- 날짜 보정 확인 필요 주문번호 `1006`

## 이 데이터셋으로 답할 수 없는 것

| 답할 수 없는 질문 | 부족한 데이터 |
|---|---|
| 상품별 이익과 마진은 얼마인가? | 상품 원가, 결제 수수료, 운영비 |
| 할인·배송비·세금을 반영한 실제 순매출은 얼마인가? | 할인액, 배송비, 세금, 결제·환불 금액 |
| 고객 재구매율과 고객 생애가치는 얼마인가? | 안정적인 고객 ID, 더 긴 구매 이력, 가입·첫 구매 시점 |
| 지난달이나 지난해 같은 달보다 성장했는가? | 2026년 8월 1~15일 외의 비교 기간 데이터 |
| 품절로 놓친 수요와 적정 재고는 얼마인가? | 재고 수량, 입출고, 품절 기간, 미판매 수요 |
| 도시별 성과 차이가 통계적으로 의미 있는가? | 더 많은 기간과 주문량, 지역별 고객·노출 규모 |
| 수량 `-1`이 반품인지 입력 오류인지 알 수 있는가? | 주문 상태, 반품·취소 사유와 처리 기록 |

현재 데이터로는 **판매 기록의 제한된 현황**만 설명할 수 있다. 원인, 수익성, 고객 유지 효과를 주장해서는 안 된다.
