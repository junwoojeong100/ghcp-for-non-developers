# 클라우드베리 월간 판매 마감 키트

이 문서 하나로 주문 내보내기 파일을 보존·점검·정리하고, 매출을 계산해 월간 요약을 작성할 수 있다.

## 1. 시작 전 준비

1. 원본 `orders.csv`를 복사하고 파일명을 `{YYYY-MM}-orders-raw.csv`로 바꾼다. 원본은 수정하지 않는다.
2. 작업 파일을 `{YYYY-MM}-orders-working.xlsx` 또는 Google Sheets로 연다.
3. 수식용 시트를 만들고 열을 아래 순서로 배치한다.

| 수식용 열 | 내용 | `orders.csv` 원본 열 |
|---|---|---|
| A | 상품명 | E `상품` |
| B | 주문일 | B `주문일` |
| C | 수량 | F `수량` |
| D | 단가 | G `단가` |
| E | 채널 | H `채널` |
| F | 확인 상태 | 새 보조 열 |
| G | 행별 매출 | 새 보조 열 |

**확인 지점:** A1:E1에 `상품명 / 주문일 / 수량 / 단가 / 채널`이 순서대로 보여야 한다.

## 2. 마감 전 데이터 체크리스트

- [ ] 원본 파일을 별도로 보관했고 작업본에서만 수정한다.
- [ ] 주문번호가 비어 있거나 중복된 행을 찾는다. 완전 중복인지 별도 주문인지 확인하기 전에는 삭제하지 않는다.
- [ ] 주문일을 실제 날짜 값 `YYYY-MM-DD`로 통일하고 대상 월 밖의 행을 별도 목록에 적는다.
- [ ] 고객명·도시·상품명·채널의 앞뒤 공백을 제거한다.
- [ ] `서울특별시/서울시/서울`, `마스킹 테이프 세트/마스킹테이프세트`처럼 같은 값을 뜻하는 표기를 기준명으로 통일한다.
- [ ] 수량이 비었거나 0 이하인 행을 `확인필요`로 표시하고 원본 행은 유지한다.
- [ ] 단가가 비었거나 숫자가 아닌 행을 별도 확인 목록에 적는다.
- [ ] 고객명이 비어 있는 행을 확인 목록에 적되 매출 계산 가능 여부와 고객 분석 가능 여부를 구분한다.
- [ ] 변경한 값마다 주문번호·컬럼·변경 전·변경 후·이유를 변경 로그에 남긴다.
- [ ] 판단이 끝나지 않은 행은 매출 합계에서 제외하고 제외 건수와 주문번호를 월간 요약에 기록한다.

### `practice/ko/orders.csv` 점검 예시

| 유형 | 주문번호 | 마감 전 처리 |
|---|---|---|
| 완전 중복 | 1007 | 같은 주문인지 확인 후 중복 1행 제거 |
| 날짜 형식 혼용 | 1002, 1006, 1012 | 실제 날짜 확인 후 `YYYY-MM-DD`로 통일 |
| 수량 판단 필요 | 1008, 1018 | 삭제하지 않고 `확인필요` 목록에 유지 |
| 단가 누락 | 1005 | 단가 확인 전 매출 계산에서 제외 |
| 고객명 누락 | 1010 | 고객별 분석 제외 여부를 기록 |
| 도시 표기·공백 | 1003, 1004, 1008, 1014 | 기준 도시명으로 통일 |
| 상품명 표기 | 1012, 1017 | `마스킹테이프 세트`로 통일 |

**확인 지점:** 해결하지 못한 행이 사라지지 않고 주문번호와 사유가 있는 별도 목록에 남아 있어야 한다.

## 3. 재사용 수식 3개

아래 수식은 A열 상품명, B열 주문일, C열 수량, D열 단가, E열 채널을 기준으로 한다. 날짜는 텍스트가 아닌 실제 날짜 값이어야 한다.

### 수식 1 — 마스킹테이프 세트의 2026년 8월 매출

**Excel**

```excel
=SUMPRODUCT((A2:A1000="마스킹테이프 세트")*(B2:B1000>=DATE(2026,8,1))*(B2:B1000<DATE(2026,9,1))*IFERROR(C2:C1000*D2:D1000,0))
```

**Google Sheets**

```excel
=IFERROR(SUM(FILTER(C2:C1000*D2:D1000,A2:A1000="마스킹테이프 세트",B2:B1000>=DATE(2026,8,1),B2:B1000<DATE(2026,9,1))),0)
```

상품과 기간이 모두 맞는 행의 `수량×단가`를 합산한다.

**테스트 케이스:** A2=`마스킹테이프 세트`, B2=`2026-08-15`, C2=`2`, D2=`8900`, E2=`웹` → 예상 결과 `17800`

### 수식 2 — 수량 확인 표시

**Excel / Google Sheets, F2**

```excel
=IF(OR(C2="",C2<=0),"확인필요","")
```

수량이 비었거나 0 이하이면 해당 행을 사람이 확인하도록 표시한다.

**테스트 케이스:** C2를 빈칸으로 둠 → F2 예상 결과 `확인필요`

### 수식 3 — 오류 없는 행별 매출

**Excel / Google Sheets, G2**

```excel
=IFERROR(C2*D2,0)
```

수량 또는 단가가 비었거나 계산할 수 없는 값이면 오류 대신 0을 반환한다.

**테스트 케이스:** C2=`빈칸`, D2=`8900` → G2 예상 결과 `0`

> 수식 3의 0은 실제 매출 0이라는 확정값이 아니라 계산 보류값일 수 있다. F열이 `확인필요`인 행과 단가 누락 행은 최종 합계에서 제외하고 별도 건수로 보고한다.

## 4. 마감 계산 순서

1. F2:G2 수식을 마지막 행까지 채운다.
2. `확인필요` 행과 단가 누락 행을 필터링해 주문번호 목록을 저장한다.
3. 유효한 행만 대상으로 총매출, 주문 수, 상품별 매출, 채널별 주문 수를 계산한다.
4. 상품 하나를 골라 `수량×단가`를 직접 더해 집계값과 대조한다.
5. 원본 행 수, 제거한 완전 중복 수, 정제본 행 수가 맞는지 확인한다.
6. 아래 월간 요약 템플릿을 채우고 검토자에게 원본·정제본·변경 로그를 함께 전달한다.

**확인 지점:** 총매출에 포함하지 않은 모든 행에 주문번호와 제외 이유가 있어야 하며, 표본 계산 하나가 집계 결과와 일치해야 한다.

```markdown

- 검토자: {검토자}
- 마감일: {YYYY-MM-DD}
- 원본 파일: {원본 파일명}
- 정제본 파일: {정제본 파일명}

## 핵심 결과

| 항목 | 결과 | 계산 기준 |
|---|---:|---|
| 유효 주문 수 | {건수}건 | {중복·취소·판단 보류 처리 기준} |
| 총매출 | {금액}원 | 유효 행의 수량×단가 합계 |
| 매출 1위 상품 | {상품명} · {금액}원 | 상품별 매출 내림차순 |
| 주문 1위 채널 | {채널명} · {건수}건 | 채널별 고유 주문 수 |

## 채널별 결과

| 채널 | 주문 수 | 매출 | 전월 대비 |
|---|---:|---:|---:|
| {채널 1} | {건수} | {금액}원 | {증감률 또는 TBD} |
| {채널 2} | {건수} | {금액}원 | {증감률 또는 TBD} |
| {채널 3} | {건수} | {금액}원 | {증감률 또는 TBD} |

## 데이터 품질

- 완전 중복 제거: {건수}건 · 주문번호 {목록}

## 해석과 후속 조치

## 승인

- 작성자 확인: {이름 / 날짜}
- 검토자 승인: {이름 / 날짜}
```
